Install in one line

On a Linux server, one command installs the gateway with a systemd service. It explains each step and asks where to expose it (this machine only, your local network, or every interface), can open the firewall, set up https with Caddy and take your model key. Afterwards: kitties gateway start|stop|restart|status|logs. Verified against the release checksums and signature.

curl -fsSL https://raw.githubusercontent.com/madkoding/kitties/main/scripts/install.sh | sudo sh
go install github.com/madkoding/kitties/cmd/kitties@latest
kitties -demo gateway   # open http://127.0.0.1:7488
kitties init
export ANTHROPIC_API_KEY=...
make image
kitties gateway

Questions

Does it touch my computer?

No. Each kitty works inside its own Docker or Podman container with a headless desktop.

Which models can I use?

Any of 11+ providers, with an API key or a subscription, chosen per kitty. Ollama keeps everything local.

What does it cost?

Nothing. Kitties is free software under GPL-3.0-or-later. You pay only your model provider, and daily budgets cap that.

Can I stop a kitty?

Always. Set limits, require approvals for risky actions, or take over the desktop live.
